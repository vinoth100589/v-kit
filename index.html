// why not just use a UI library

Ownership beats installation.

Component libraries are usually a dependency you're stuck maintaining. V-Kit is files you own.

01

No breaking upgrades

There's no package.json entry to bump, no changelog to read before your build breaks. The component is in your repo — it changes when you change it.

02

No bundle bloat

You take the 3 components you need, not the 80 you don't. Every download is self-contained — no v-kit runtime hiding in your node_modules.

03

Theming that isn't a fight

4 themes ship inside every single file as plain CSS variables. Override one token, or swap the whole palette — no theme provider, no context wrapper.
